# sat-backend-cdcl

[sat-protocol](https://github.com/egao1980/sat-protocol) backend: conflict-driven clause learning in the MiniSat style. Two watched literals, 1UIP learning with clause minimisation, VSIDS with phase saving, restarts, learnt-clause reduction, and assumption-based final-conflict cores for `backend-final-conflict`. Pure Lisp, no dependencies beyond sat-protocol.

**Status:** planned (slice L2b-3, Track L). Brief: [cl-stack/docs/capabilities/logic.md](https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/logic.md#l2b-3--sat-backend-cdcl-010-planned-cl-stack370). Motivation: proving optimality on weighted sequence-labelling / chain selection problems ([cl-stack#370](https://github.com/egao1980/cl-stack/issues/370)).
